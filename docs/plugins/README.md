# Плагины

Плагины добавляют исполняемые возможности поверх Core: команды, lifecycle
репозитория, состояние и, при необходимости, расширение агента. Они используют
публичный Plugin SDK и не становятся частью Core.

[Создать и добавить свой плагин](../user/creating-addons.md): генерация файлов, заполнение, проверка и подключение к проекту.

| Плагин | Назначение | Документ |
|---|---|---|
| OpenSpec Graph | Граф требований, Changes и Repository Impact | [OpenSpec Graph](openspec-graph.md) |
| CodeGraph | Локальная навигация по коду | [CodeGraph](codegraph.md) |
| Change Tracking | Связь задач OpenSpec с ревизиями реализации | [Change Tracking](change-tracking.md) |

Подключение, обновление, диагностика и удаление плагинов и расширений описаны в
[отдельном руководстве](operations.md).

Контракт SDK, структура package и разработка внешнего плагина описаны в
[руководстве для разработчика плагинов](development.md). Пользовательское назначение
сущностей находится в [документации для пользователей](../user/entities.md).
