# Архив документации

В этой директории сохранён только защищённый исторический workplace reference. Он не
является актуальным источником требований или runbook.

Актуальные пользовательские документы находятся в
[`docs2/user/`](../../docs2/user/README.md), технические — в
[`docs2/technical/`](../../docs2/technical/README.md).

## Содержимое

- [`reference/OpenSpec для команды.md`](<reference/OpenSpec для команды.md>) —
  immutable workplace-гайд по раннему multi-repository flow; сохранён без
  актуализации по прямому правилу проекта и заменён текущим
  [`docs2/user/team-flow.md`](../../docs2/user/team-flow.md).

Остальные исторические планы, прототипы и audits удалены из рабочего дерева; при
необходимости они восстанавливаются из Git history.
