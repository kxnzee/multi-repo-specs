# Архив документации

В этой директории хранятся документы предыдущих архитектурных и продуктовых
итераций. Они сохранены как исторический контекст, но не являются актуальным
источником требований или планом реализации.

Перед использованием архивного документа необходимо прочитать предупреждение в его
начале и перейти по указанной ссылке на актуальный документ.

## Содержимое

- `OpenSpec-Orchestrator-Core-Implementation-Plan.md` — предыдущий архитектурный план,
