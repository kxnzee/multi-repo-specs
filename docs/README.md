# Документация проекта

Документация разделена по аудитории. Если вы используете OpenSpec Orchestrator в
проекте, начните с [пользовательской документации](user/README.md).

| Раздел | Для кого | Статус |
|---|---|---|
| [`user/`](user/README.md) | Владелец, Аналитик, Разработчик, Тестировщик, Лид и оператор пилота | Актуальные инструкции и командный процесс |
| [`technical/`](technical/README.md) | Разработчики и ревьюеры Orchestrator | Актуальный продуктовый и технический контракт |
| [`archive/`](archive/README.md) | Читатели защищённого workplace reference | Исторический источник, не использовать как runbook |

Обычному пользователю не нужно читать `technical/` или архив, чтобы пройти штатный
процесс команды. Актуальную документацию OpenSpec следует брать из установленной
версии продукта или её официального versioned источника, а не из копии в этом repo.
