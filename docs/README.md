# Документация проекта

Документация разделена по аудитории. Если вы используете OpenSpec Orchestrator в
проекте, начните с [пользовательской документации](user/README.md).

| Раздел | Для кого | Статус |
|---|---|---|
| [`user/`](user/README.md) | Analyst, Developer, QA, Lead и оператор пилота | Актуальные инструкции и командный процесс |
| [`technical/`](technical/README.md) | Разработчики и ревьюеры Orchestrator | Актуальный продуктовый и технический контракт |
| [`openspec-origin-docs/`](openspec-origin-docs/README.md) | Тем, кому нужен справочник самого OpenSpec | Оригинальная документация OpenSpec, не инструкция этого проекта |
| [`archive/`](archive/README.md) | Исследователи истории проекта | Неактуальные материалы, не использовать как runbook |

Обычному пользователю не нужно читать `technical/`, исходную документацию OpenSpec
целиком или архив, чтобы пройти штатный процесс команды.
