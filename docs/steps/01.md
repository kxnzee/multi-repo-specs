## 01. Explore запроса

Шаг выполняет Change Owner для нового ticket.

### 1. Подготовьте запрос

Нужны:

- ticket key, например `PAY-412`;
- краткое намерение: что требуется понять и зачем;
- чистые и актуальные checkout центрального Store и предполагаемых Code Repositories.

Обновите Store:

```bash
git switch <default-branch>
git pull --ff-only
```

Обновите нужные Code Repositories:

```bash
git -C <workspace>/src/<repository-id> switch <default-branch>
git -C <workspace>/src/<repository-id> pull --ff-only
```

### 2. Запустите Explore

Из корня Store выполните:

```bash
sdd explore --ticket <ticket-id>
```

Выберите репозитории для исследования и введите намерение. Пример намерения:

```text
Понять, как показывать пользователю актуальный статус платежа в UI на основе данных API.
```

### 3. Передайте результат агенту

Команда вернёт готовое сообщение, начинающееся с `/opsx-explore`. Откройте новую сессию поддерживаемого агента из корня Store и вставьте сообщение целиком без изменений.

Ответьте на уточняющие вопросы агента. На этом шаге не создавайте Change, ветку или PR.

### Успешный результат

Переходите к [шагу 02](02.md), когда:

- проблема и ожидаемый результат понятны;
- определены затронутые репозитории и внешние системы;
- блокирующих вопросов нет;
- Change Owner решил продолжать работу.

Если сессия Explore потеряна, повторите этот шаг.
