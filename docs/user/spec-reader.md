# Человекочитаемые мастер-спеки

Встроенный необязательный Extension `spec-reader` предоставляет скилл
`specs-to-business`: агент преобразует требования и сценарии мастер-спек в обычный
текст для бизнеса. Он работает с `openspec/specs/` независимо от schema Changes.

В Store добавьте и подключите Extension к выбранному Agent:

```bash
openspec-orch extension init spec-reader
openspec-orch extension connect spec-reader
```

После подключения используйте штатный механизм навыков Claude, Qwen или GigaCode
либо попросите агента обычным текстом:

> Используй specs-to-business. Создай человекочитаемую документацию по capability
> authentication из мастер-спеки этого Store.

Результат — `docs/business/authentication.md`. Вложенные пути сохраняются:
`payments/refunds` становится `docs/business/payments/refunds.md`.
Без указанной области агент уточняет выбор; он не начинает полный обход автоматически.

Для всей системы запросите полный режим явно:

> Используй specs-to-business. Собери документацию по всем мастер-спекам этого Store.

Агент создаст отдельный документ для каждой capability и `docs/business/README.md`
с оглавлением. Документы содержат описание поведения, ссылки на источники, revision
и хеш исходного файла, а также соответствие каждому требованию и сценарию.
Противоречия и неясности источника отмечаются отдельно.

Повторный запуск обновляет выбранную область. Один документ не обновляет общее
оглавление. Файлы, созданные скиллом, имеют отметку генератора; документы без неё
и явно обозначенные ручные дополнения требуют решения о способе обновления.
Документы исчезнувших capabilities автоматически не удаляются.

Это производное представление, а не подтверждение реализации или согласования
требований. Исходные `spec.md` остаются источником истины. Точность пересказа проверяет
агент; перед использованием как согласованного документа нужен обычный review.
Генерация запускается пользователем: автоматического обновления после Archive,
проверки актуальности в CI и экспорта HTML/PDF в этой версии нет.

При повторном запуске агент перечитывает целевой документ целиком, даже если
исходная Master Spec не менялась. Generator-отметка не подтверждает отсутствие
ручных дополнений. Перед заявлением о полном покрытии проверяются обе ссылки
каждой строки соответствия: на источник и на существующий раздел результата.
