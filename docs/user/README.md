# Документация для пользователей

Читайте по порядку: от установки до работы с Change. Каждый документ отвечает на
один вопрос и ссылается на следующий шаг.

Примеры написаны для GigaCode. Для Claude и Qwen см. [отличия](other-agents.md).

Роли в колонке «Кто» взяты из [процесса работы над Jira Story](story-delivery-process.md#роли).
Один человек может совмещать несколько ролей.

## Начало работы

| Шаг | Когда | Кто | Документ |
|---|---|---|---|
| 0 | Перед началом работы | Все | [Основные понятия](concepts.md): Store, репозитории, Change, сессии агента |
| 1 | Один раз на каждой машине | Все | [Установка](installation.md): Orchestrator, OpenSpec, CLI и регистрация агента |
| 2а | Проекта ещё нет | Аналитик | [Создание нового проекта](new-project.md): `init`, первый `connect`, публикация Store |
| 2б | Проект уже есть у команды | Все остальные участники | [Подключение к существующему проекту](join-project.md): clone Store, `connect`, `doctor` |
| 2в | Хотите сделать 2а или 2б через GigaCode | Как в 2а или 2б | [Настройка через агента](setup-via-agent.md): создание и подключение проекта через MCP |
| 3 | После создания проекта, до первого Change | Аналитик | [Бизнес-контекст](project-context.md): описание продукта для агента |

## Работа с Change

| Этап | Кто делает | Кто проверяет и принимает | Где | Документ |
|---|---|---|---|---|
| Обзор | Все | | Store и репозитории | [Жизненный цикл Change](change/README.md): этапы, команды агента, выбор schema |
| 1. Planning | Аналитик | Разработчик, тестировщик, лид разработки | Store | [Planning](change/planning.md): требования, план, принятие; baseline для работающей системы |
| 2. Apply | Разработчик | Ревьюеры Code PR | Репозиторий кода | [Apply](change/apply.md): реализация в каждом назначенном репозитории |
| 3. Verify | Тестировщик | Тестировщик (`PASS` или `FAIL`) | Store | [Verify](change/verify.md): проверка кандидата и решение человека |
| 4. Archive | Аналитик | Ревьюеры Story Store PR, затем UAT и владелец продукта | Store | [Archive](change/archive.md): перенос дельты в Master Specs |
