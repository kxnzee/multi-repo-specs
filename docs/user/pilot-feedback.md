# OpenSpec Orchestrator: журнал обратной связи пилота

Этот файл содержит только наблюдаемые факты реальных Changes текущего пилота.
Здесь не проектируются решения и не ведётся технический changelog.
Pre-pilot engineering findings не дублируются в активной документации и доступны в
Git history.

- Где пользователь боялся ошибиться:

Если проблемы не наблюдалось, напишите это явно. Возможное решение переносится в
отдельный Change, ADR или `BACKLOG.md` только после решения владельца; этот журнал
фиксирует факт и его влияние, но не подменяет проектирование.
