# Техническая документация

Этот раздел предназначен для разработки, ревью и развития OpenSpec Orchestrator.
Пользовательский процесс и команды находятся в
[`docs/user/`](../user/README.md).

## Актуальные документы

1. [Alpha Concept](alpha-concept.md) — нормативные границы, термины и контракт Alpha.
2. [Alpha Implementation Plan](alpha-implementation-plan.md) — техническая
   декомпозиция реализации Alpha.
3. [External Integrations](external-integrations.md) — границы Jira, Zephyr и
   Confluence до появления Plugin API.
4. [Разработка Core](development.md) — структура исходного кода и проверки.
5. [Backlog после пилота](../../BACKLOG.md) — кандидаты развития, которые не входят в
   текущую Alpha.

Исторические проекты и планы не дополняют текущий контракт и находятся только в
[`docs/archive/`](../archive/README.md).
