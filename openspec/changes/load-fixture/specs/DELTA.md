## ADDED Requirements

### Requirement: Индикатор фикстуры на экране (UI)
Система MUST отображать тестовый индикатор фикстуры в интерфейсе, когда пилотный флаг включён.

#### Scenario: FIX-001 Индикатор виден при включённом флаге
- GIVEN пилотный флаг `load-fixture` включён для пользователя
- WHEN пользователь открывает главный экран
- THEN интерфейс показывает тестовый индикатор фикстуры

#### Scenario: FIX-002 Индикатор скрыт по умолчанию
- GIVEN пилотный флаг `load-fixture` выключен
- WHEN пользователь открывает главный экран
- THEN интерфейс не показывает тестовый индикатор фикстуры

### Requirement: Обработка тестового события фикстуры (Backend)
Система MUST принимать и подтверждать тестовое событие фикстуры кодом ответа `202 Accepted`.

#### Scenario: FIX-003 Событие принято
- GIVEN пилотный флаг `load-fixture` включён
- WHEN backend получает тестовое событие фикстуры
- THEN backend отвечает `202 Accepted` и записывает событие в лог фикстуры
