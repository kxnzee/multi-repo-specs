## Purpose

Отображение статусов модулей обучения на веб-странице с получением данных из артефактов курса и корректной обработкой отсутствия данных.

## ADDED Requirements

### Requirement: Отображение статусов модулей
Система SHALL отображать список модулей курса с их текущим статусом. Каждый модуль SHALL иметь один из трёх статусов: пройден, в процессе, план. Статус каждого модуля SHALL быть визуально различим.

#### Scenario: Модули с разными статусами
- **WHEN** артефакты курса содержат модули со статусами пройден, в процессе и план
- **THEN** система отображает все модули, каждый со своим статусом, визуально различимым

#### Scenario: Все модули с одинаковым статусом
- **WHEN** артефакты курса содержат модули, все которых имеют статус план
- **THEN** система отображает все модули со статусом план

### Requirement: Получение данных о прогрессе из артефактов курса
Система SHALL получать данные о модулях и их статусах из артефактов курса, поставляемых фреймворком обучения. Контракт статусов SHALL состоять ровно из трёх значений: пройден, в процессе, план.

#### Scenario: Артефакты курса доступны
- **WHEN** артефакты курса доступны и содержат корректные данные о модулях
- **THEN** система извлекает из них перечень модулей и их статусы

### Requirement: Обработка отсутствия данных
Система SHALL отображать уместное пустое состояние, когда данные о прогрессе недоступны.

#### Scenario: Артефакты курса отсутствуют
- **WHEN** артефакты курса не найдены
- **THEN** система отображает сообщение об отсутствии данных о прогрессе обучения

#### Scenario: Артефакты курса не содержат модулей
- **WHEN** артефакты курса доступны, но не содержат ни одного модуля
- **THEN** система отображает сообщение об отсутствии данных о прогрессе обучения
