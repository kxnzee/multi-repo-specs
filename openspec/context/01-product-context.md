# Product context

## Назначение продукта

Продукт помогает командам согласовывать спецификации между репозиториями.

## Пользователи и участники

Команды разработки, которые работают с несколькими репозиториями.

## Ключевые бизнес-сценарии

Согласование изменений спецификации, затрагивающих несколько репозиториев.

## Границы продукта

Входит: управление спецификациями между репозиториями. Не входит: реализация кода.
