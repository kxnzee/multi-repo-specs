# Проверка влияния через OpenSpec Graph

Эти инструкции применяются, когда OpenSpec Graph подключён к выбранному Store.
Они дополняют текущий workflow проверки Repository Impact, независимо от schema.

При подготовке или проверке Change обязательно проверь Repository Impact через
`get_spec_change_impact` с `change_id` выбранного Change. Для другого Store передай
его локальный `store_repository_id` из реестра; не подменяй выбранный Store основным.
Если MCP-вызов недоступен, выполни
`openspec-orch plugin exec --repo <store-id> openspec-graph inspect --json`.

Проверяй актуальные файлы после изменений Proposal или Delta Specs. Рассмотри
диагностику, затронутые репозитории и capabilities; исправь ошибки в запрошенных
артефактах или явно отрази нерешённые проблемы в результате проверки. Ошибка вызова
или недоступность проверки означает «не проверено», а не успешный результат.
Проверка Graph дополняет штатную валидацию OpenSpec и не подтверждает реализацию
сценариев, согласие команд или приёмку результата.

Если Graph не подключён к выбранному Store, эти инструкции не требуют его
установки: следуй текущему workflow и доступным проверкам.
