# Raw context materials

`_raw/` — каталог входящих материалов для `/sdd-context`.

Сюда помещаются уже существующие сведения о продукте: vision, требования, описания архитектуры, доменные термины, заметки и результаты интервью. Здесь также можно сохранить исходные материалы о принятом решении, обнаруженном ограничении или произошедшем инциденте, если из них требуется извлечь устойчивые правила проекта. Материалы из Confluence и других систем можно сохранить обычным copy-paste в файл `.md`; специальный экспорт не требуется.

При каждом вызове `/sdd-context` агент заново сканирует все `_raw/**/*.md`, последовательно читает их и сравнивает утверждения только с нормативным контекстом, Master Specs и принятыми ADR центрального Store. Code Repositories в этом процессе не читаются. Уже подтверждённые сведения повторно не добавляются, а новые, изменённые или противоречащие источникам утверждения уточняются у пользователя.

Raw-файл не является источником нормативного факта. Подтверждённые сведения переносятся в соответствующие файлы `openspec/context/`.

## Хранение и удаление материалов

- Агент не удаляет raw-файлы автоматически после обработки.
- Файл можно сохранить в Git как первичный источник и свидетельство происхождения принятого правила.
- Повторный запуск `/sdd-context` снова прочитает сохранённый файл, сравнит его с нормативным контекстом и не должен повторно добавлять уже подтверждённые сведения.
- Временный, устаревший или больше не нужный файл удаляется только отдельным согласованным изменением после переноса необходимых сведений в нормативный контекст.
- Секреты, токены, приватные ключи, персональные данные и другие сведения с ограниченным доступом нельзя помещать в `_raw/`.
