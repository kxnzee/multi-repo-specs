# Raw context materials

`_raw/` — каталог входящих материалов для `/sdd-context`.

Сюда помещаются уже существующие сведения о продукте: vision, требования, описания архитектуры, доменные термины, заметки и результаты интервью. Материалы из Confluence и других систем можно сохранить обычным copy-paste в файл `.md`; специальный экспорт не требуется.

При каждом вызове `/sdd-context` агент заново сканирует все `_raw/**/*.md`, последовательно читает их, сравнивает утверждения с нормативным контекстом, Master Specs и зарегистрированными репозиториями. Уже подтверждённые сведения повторно не добавляются, а новые, изменённые или противоречащие источникам утверждения уточняются у пользователя.

Raw-файл не является источником нормативного факта. Подтверждённые сведения переносятся в соответствующие файлы `openspec/context/`. Исходные материалы можно сохранить в Git для воспроизводимости или удалить отдельным согласованным изменением, когда они больше не нужны.
