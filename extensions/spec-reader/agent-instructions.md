# Spec Reader

Для создания или обновления человекочитаемой документации по мастер-спекам OpenSpec
используй навык `specs-to-business` штатным механизмом навыков Agent. Его инструкции
находятся в `skills/specs-to-business/SKILL.md` относительно корня этого Extension.
Запрос может выбирать одну capability или явно все мастер-спеки.

Extension работает с обычным `openspec/specs/`, независимо от schema Changes и
наличия Orchestrator MCP. Генерация запускается по запросу пользователя; подключение
Extension и обновление мастер-спек сами по себе документы не создают.
