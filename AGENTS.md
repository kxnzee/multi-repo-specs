# Правила агента — `project-specs`

Область действия: этот файл описывает правила для агентов, работающих в **этом** репозитории (Master Specs, активные изменения, Baseline-теги). Аналогичные файлы для `ui` и `backend` заводятся в соответствующих репозиториях — они вне текущего репозитория и не создаются здесь.

Перед любой задачей прочитать `openspec/context/00-start-here.md` и перечисленные там файлы. Каталог `openspec/context/_raw/` не является нормативным источником.

## Как собирать

Сборки продукта нет. Проверки репозитория:

```bash
npx --yes @fission-ai/openspec@1.7.0 validate --all
cd harness && npm test
```

## Как тестировать

Для harness есть Node-тесты; для требований дополнительно выполняются проверки OpenSpec:

```bash
npx --yes @fission-ai/openspec@1.7.0 config list      # текущий профиль
npx --yes @fission-ai/openspec@1.7.0 schemas          # доступные workflow-схемы
```

Перед Planning PR — чек-лист `templates/planning-pr-template.md` заполнен целиком, `templates/impact-and-design.schema.md` соблюдён.

## Что не трогать автономно

Решения, которые не принимает агент (I.3.5, раздел 6 профиля Pilot Core):

- утверждение бизнес-требований;
- архитектурные решения без ревью;
- признание тестового покрытия достаточным;
- согласование исключений, включая отступление от защитного критерия;
- включение релизного флага в production;
- финализация Change (применение дельт к Master Specs);
- согласование редакционной правки запертого требования;
- авторизация обхода любой из пяти блокирующих проверок;
- решение о переходе на Scale Profile.

## Baseline-теги

Никогда не удалять и не перезаписывать теги `spec-baseline/*`, включая служебное пространство `spec-baseline/_*/v<N>` (протестовые/fixture-теги). Маска защиты распространяется на них тоже — это то самое свойство, которое проверка доказывает (раздел 8 профиля Pilot Core).

## `candidate_repositories`

Список репозиториев для `sdd fetch-repos` берётся только из поля `candidate_repositories` в `impact-and-design.md`. Не добавлять репозитории через аргументы командной строки и не читать репозитории, не указанные в этом поле.
