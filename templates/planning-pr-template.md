| ID пакета | Репозиторий | Тип | Scenario ID (только для `implements`) | AC-* (только для `enables`) | Отмечено |
|---|---|---|---|---|---|
| `UI-01` | `ui` | `implements` | | — | ☐ |
| `BACKEND-01` | `backend` | `implements` | | — | ☐ |
| `CONFIG-01` | `configuration` | `enables` | — | | ☐ |
