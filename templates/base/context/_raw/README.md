# Raw context materials

`_raw/` содержит исходные материалы для команды `/openspec-base-context`: существующие
описания продукта, архитектурные заметки, результаты интервью, решения и сведения об
инцидентах.

- Raw-файл не является подтверждённым контекстом сам по себе.
- Команда `/openspec-base-context` использует эти материалы только как raw evidence и
  переносит только подтверждённые устойчивые утверждения в тематические context-файлы.
- Исходные материалы не удаляются автоматически.
- Не помещайте сюда секреты, credentials и лишние персональные данные.
