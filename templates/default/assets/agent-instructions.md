# Инструкции агента для Store

Этот репозиторий — центральный OpenSpec Store со спецификациями и согласованными
решениями проекта. Это не Code Repository и не репозиторий разработки Orchestrator.

Перед работой:

1. Прочитай `openspec-orch.yaml`: там зарегистрированы Store, Code Repositories,
   выбранный Agent, Extensions и Plugins.
2. Начни с `openspec/context/00-start-here.md` и открывай только относящийся к задаче
   бизнес-контекст. Материалы `_raw/` не являются подтверждёнными фактами.
3. Для существующего Change определи точные ID и schema. Получи актуальные status,
   инструкции артефакта и следующий шаг через Orchestrator MCP.

Requirements, Master Specs и Changes находятся в `openspec/`. Правила и зависимости
артефактов определяют `openspec/config.yaml`, schema выбранного Change и подключённые
Extensions. Не смешивай их workflow и не угадывай следующий этап.

Реализацию выполняй только в зарегистрированных Code Repositories. Не создавай там
локальные `openspec/changes/`. Не придумывай роли, согласования, ветки или направления
PR: используй только явно предоставленные правила проекта и полномочия пользователя.
