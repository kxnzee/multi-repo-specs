# Raw context materials

`_raw/` содержит исходные материалы о бизнесе приложения: описания продукта,
результаты интервью и сведения о принятых решениях.

- Raw-файл не является подтверждённым контекстом сам по себе.
- В тематические разделы входят только сведения, подтверждённые источником или
  владельцем. Неподтверждённое остаётся исходным материалом или явным пробелом.
- Исходные материалы не удаляются автоматически.
- Не помещайте сюда секреты, credentials и лишние персональные данные.
