# Raw context materials

`_raw/` содержит исходные материалы для команды `/spec-driven-extended-context`: существующие
описания продукта, архитектурные заметки, результаты интервью, решения и сведения об
инцидентах.

- Raw-файл не является подтверждённым контекстом сам по себе.
- Команда `/spec-driven-extended-context` использует эти материалы только как источник
  кандидатов в факты и переносит в тематические context-файлы лишь устойчивые
  утверждения, подтверждённые постоянным источником или владельцем.
- Исходные материалы не удаляются автоматически.
- Не помещайте сюда секреты, credentials и лишние персональные данные.
