# Исходные материалы

Сюда помещают имеющиеся описания продукта, предметной области, процессов,
политик и принятых решений. Достаточно читаемого текста с названием источника,
известными датой и автором. Материалы нужны до интервью, чтобы не повторять вопросы.

Размещение файла здесь не означает принятия всех его утверждений. Противоречия
и неподтверждённые сведения уточняются у владельца. Исходные материалы сохраняются;
секреты и лишние персональные данные сюда не помещают.
