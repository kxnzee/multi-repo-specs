# Upstream attribution

This Template adapts the schema-level integration pattern and artifact lifecycle from
[`danielhanold/superspec`](https://github.com/danielhanold/superspec), schema version 4,
commit `e1c8f417ee3601208416d988ba3b37d83ddb63f2`.

The adaptation preserves the upstream skill-driven lifecycle through Apply and Verify
while mapping it to a central multi-repository OpenSpec Store, exact Repository IDs,
per-repository worktrees, explicit human acceptance and team-owned Release.
Concrete instructions, artifact contracts and authority boundaries differ from upstream.
